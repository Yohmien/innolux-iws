# IWS 提交与远端同步规约

2026-10-24。适用于当前后端、Web、PDA 三仓库。本文随个人仓库留存；本机代理的当前权威入口为[集中项目规约](C:/code/company/doc/innolux-iws/agent.md)。

## 提交范围

按独立能力和依赖顺序拆分可审阅的小提交。后端产品代码、构建配置与运行 SQL 单独提交；文档、测试、Skill 和个人规划放到后续个人提交。保留任务开始前已有的无关修改，不把它们混入交付。

提交与推送分别按当前任务授权执行。核对完整暂存差异、凭据和 `git diff --cached --check`，不使用跳过钩子或强推的方式完成同步。

## 后端远端

| 远端 | 归属 | 同步内容 |
| --- | --- | --- |
| `upstream` | 来源 Gitee | 产品 `main`：代码、构建配置、运行 SQL |
| `origin` | 个人 Gitee | 全部产品提交，以及文档、测试、项目 Skill |
| `github` | 个人 GitHub | 与个人 Gitee 相同 |

每次推送前用 `git remote -v` 核对身份。保留现有 upstream pre-push 保护，文档、测试和 Skill 不进入来源仓库。

个人仓库必须是 upstream 的父集：完整包含产品文件和提交历史，再叠加个人材料。首次交付先同步产品 `main`；随后在以产品提交为祖先的 `personal/*` 分支提交个人材料，用显式 refspec 推送到个人远端 `main`。本地产品 `main` 保持产品历史。

后续产品变更从产品分支继续，再将新产品提交合入个人分支；必须保留个人 `main` 已有材料。个人 `main` 已领先时，不再尝试用落后的产品分支覆盖它。

交付时核对三个远端真实提交，确认 `upstream/main` 是个人交付分支的祖先；仅文件相似或复制目录不代表满足父集要求。

## Web、PDA 与本机入口

Web 产品代码及配套测试推送其来源 `origin`，文档与项目 Skill 统一保存在后端个人仓库。PDA 无本次变更时不制造提交。

三个仓库的本机 `AGENTS.md` 继续由 `.git/info/exclude` 忽略并指向集中规约。计划事件领域 Skill 与 RuoYi 薄路由暂仅安装在后端 `.agents/skills`；Web/PDA 通过集中指针读取同一份内容。全局通用 Skill 保持原状，不复制通用正文。
