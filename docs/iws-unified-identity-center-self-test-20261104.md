## 安全与故障观察

以下为可选专项观察，当前稳定窗口不再主动故障注入。普通功能自测不需要停止数据库、Redis或中心；如另做故障测试，只在已确认的隔离环境按恢复说明执行，不修改真实数据库或共享/生产服务。

- Job 普通用户验证未授权 group/namespace 的列表、详情、执行和批量操作拒绝，管理员及真正执行器按原权限运行。
- AI 普通用户验证模型/知识库/应用和主体隔离；人员 HTTP 流关闭、服务端 gRPC 取消、上游模型 HTTP 取消分别记录，不合并成一个通过。
- Monitor 人员会话与机器 Basic 分别验证；人员撤权不保留实例管理能力，机器认证不能进入人员控制台。
- 中心/Redis/数据库故障时，新的业务写请求拒绝；只读租约有界，恢复后重新校验；推送旧连接按规定时间关闭，合法对照不误踢。
- 切 A/B 时观察请求、上传/下载、字典和长连接目标；旧异步响应、旧退出及迟到登录事务不清掉新会话，不重放 UNKNOWN/离线待确认业务命令。
- 开发/发布实际支持的 HTTP/HTTPS、子路径、跨站及禁第三方 Cookie 按最终覆盖矩阵执行，不以 Vite 代理存在推定发布环境已通。
