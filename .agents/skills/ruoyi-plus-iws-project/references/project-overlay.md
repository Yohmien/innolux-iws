## 仓储页面复用

没有特殊要求时，默认尽可能复用现有 `IwsCrudPage`、CRUD hooks、通用 API 与元数据注册。保留用户在权限和字段能力范围内调整列、查询条件、排序、分页以及模板下载、导入和导出的能力，不因后端需要业务或计划就把标准表页降为只读或默认重建整套表单与工具栏。

新增、修改、删除和导入可以继续使用标准模板入口：后端按登记的tableCode、字段白名单和对象权限，将一次请求路由到普通原子CRUD及审计，或必要的业务命令/计划挂载。禁止任意表名写入和前端连续调用多个动作来隐藏流程。业务受理与实际生效分别返回和展示；确需补充原因、影响预览、版本冲突或实例状态时，优先使用已存在的适配能力，缺口以最小共享扩展补齐，不宣称未实现的hook已存在。

树形空间、容量条带、家谱、流程图及复杂交互有具体特殊需求时，可使用局部组件或专门视图，并尽可能复用查询、元数据、表格和导出底座；说明特殊需求与现有模板缺口即可，不新增审批流程。安全约束、权限、已发布版本只读和历史不可修改的边界仍由后端执行；“用户可调整”不表示可覆盖这些边界。具体组件入口见[Web复用指南](C:/code/company/doc/innolux-iws/references/web.md)。
